주요 기능

멀티포트 동시 운영

포트 개수 제한 없이 여러 COM-IP 브릿지를 동시에 운영할 수 있습니다.

TCP Server / Client / UDP

서버, 클라이언트, UDP 모드를 포트별로 독립 설정 가능합니다.

자동 재연결

연결 끊김 시 설정한 간격으로 자동 복구합니다.

실시간 데이터 모니터

Hex/ASCII 데이터를 실시간으로 확인. 방향별 색상 구분.

시스템 트레이

최소화 시 트레이로 이동. 백그라운드에서 조용히 동작합니다.

설정 내보내기 / 가져오기

JSON 파일로 설정을 저장하고 다른 PC로 이동 가능합니다.

시스템 요구사항

  • Windows 10 / 11 (64-bit)
  • .NET 런타임 불필요 (자체 포함)
  • COM 포트 장치 (USB-Serial 어댑터 등)
  • 네트워크 연결 (TCP/IP 통신용)
